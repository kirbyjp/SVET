# SVET
Static Vacuum Excitation Theory (SVET): A capacity‑limited Planck‑scale physical vacuum governed by minimal local rules and assumptions that unify General Relativity (GR) and Quantum Gravity (QG) into a finite, divergence‑free formulation that eliminates renormalization, replaces singularities with finite‑core black holes, and reproduces the observables found in the universe.
