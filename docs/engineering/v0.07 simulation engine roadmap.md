### v0.07 Simulation Engine Roadmap: Data Export & Validation Suite

The table below outlines the software engineering deliverables, priorities, and risk metrics governing the development of the v0.07 simulation data exporter and automated validation pipeline.

| Deliverable | Priority | Target Phase | Risk if Omitted | Action / Status |
| :--- | :--- | :--- | :--- | :--- |
| **Atomic CSV + NDJSON Export + Manifest** | P0 | v0.07 P0 | High — data corruption / unusable exports | Implement now |
| **Canonical Header Assertion** | P0 | v0.07 P0 | High — schema drift, downstream parsing failures | Implement now |
| **`Psi_edge` Four-Corner Average** | P0 | v0.07 P0 | Medium — incorrect edge sampling for reflective boundary conditions | Implement now |
| **NDJSON Flush + Incremental Hashing** | P0 | v0.07 P0 | High — memory exhaustion for large runs if not streaming | Implement now |
| **Percent Normalization + `percent_outlier` Flag** | P1 | v0.07 P1 | Medium — misleading or un-scaled diagnostics | Move to P0 if percentage anomalies are observed |
| **`csv_schema.json` and CI Tests** | P1 | v0.07 P1 | Medium — software regression and schema drift | Implement in P1 |
| **Chunked Export and Compression** | P2 | v0.07 P2 | Low initially; required for large-scale runs | Implement in P2 |
| **Export Telemetry and Monitoring** | P2 | v0.07 P2 | Medium for real-time operations monitoring | Implement in P2 |
| **Validator CLI and CI Integration** | P0/P1 | v0.07 P0 (validator) / P1 (CI) | High — unable to validate simulation exports automatically | Validator P0; CI integration P1 |
